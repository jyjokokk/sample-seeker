# Agent instructions

## Task tracking (Trello)

Tasks live on the [Sample Seeker Trello board](https://trello.com/b/YKmqR6fT/sample-seeker). The board's development plan and working agreements are on card #1.

- Refer to cards by their **card number**, prefixed with `#` where it fits (e.g. `#6`), in chat, commit messages and branch names.
- The card number is in the card URL: `trello.com/c/<shortLink>/<number>-<slug>`. For example, `trello.com/c/8W8bshdh/6-m1-index-sample-folders-engineindex` is `#6`.
- The number stays the same when a card is renamed or moved between lists.
